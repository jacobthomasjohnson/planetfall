# Planetfall

A browser-based space management game built with Next.js, React, Tailwind CSS, and Zustand. Pick a planet, click to trigger events, and manage its population, resources, technology, and travel from a set of panels driven by a single game store.

**Status:** work in progress. The planet view, event animations, activity log, and page navigation work; the management screens are still being built.

## What's here

- **Planet view** with size and color variations and a hover HUD.
- **Click events** that roll for an outcome and play an animation over the planet.
- **Activity log** component that records what happens.
- **Section navigation** across operations, population, resources, stats, technology, and travel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
